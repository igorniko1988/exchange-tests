# exchange-tests

Учебный проект: фреймворк автотестов для тестовой биржи, который пишется с нуля **руками**.
Полный цикл как на работе: uv → структура → ветка → PR → ревью → merge → CI.

## Роли

- **Код пишет пользователь.** Claude не пишет код фреймворка и тестов и не копирует эталон.
- Claude: выдаёт задание этапа с критериями «готово», даёт теорию и вопросы с собеседований, делает ревью.
- Git-команды (`commit`, `push`, `merge`) пользователь выполняет сам.
- Этот файл — единственный, который положил Claude.

## Стенд и эталон

- Стенд (сервис биржи): `~/api_learning/exchange/`. Запуск: `cd ~/api_learning && docker compose up -d`, порт `:8080`.
- Эталон: `~/api_learning/framework/`. Только читать для сравнения, не копировать.
- GitHub: `igorniko1988/exchange-tests`.

## Формат ревью

1. Пользователь пушит ветку и пишет «ревью <ветка>».
2. Claude выполняет `git fetch` и `git diff main...origin/<ветка>`.
3. Замечания по уровням: тест врёт → надёжность → секреты → архитектура → поддержка.
   Для каждого замечания: проблема, к чему приведёт, как исправить.
4. Вердикт: «можно мержить» или «сначала исправить пункты N».
